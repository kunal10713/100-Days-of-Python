# Higher or Lower: Followers Game

This project is a fun command-line game where the player has to guess who has more social media followers between two randomly selected public figures. The player's score increases with each correct guess, and the game continues until they make a mistake.

## How to Play

1. Clone this repository.
2. Run the script using Python.
3. The game will display two public figures, and you will need to guess which one has more followers.
4. Type 'A' if you think the first figure has more followers, or 'B' if you think the second figure does.
5. Your score will increase with each correct guess, and the game continues until you guess wrong.

## Prerequisites

- Python 3.x
- The `colleted_data.py` file containing the dataset of public figures (not included here).

## Running the Game

To start the game, simply run the following command:
python higher_lower.py


## Features
1. Randomly selects two figures from a dataset.
2. Keeps track of your score.
3. Displays your final score when the game ends.
